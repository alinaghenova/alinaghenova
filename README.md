### 📁 Избранные технические кейсы в портфолио

#### 1. Платформа автоматизации жилых пространств «Умный дом» (Дипломный проект)
*   **Что сделано:** Спроектировала MVP-версию платформы на 27 функциональных фич (бэклог из 8 эпиков). Разработала техническое задание (спецификацию SRS), логические диаграммы потоков данных (DFD) и сформировала программу и методику испытаний (ПМИ) по стандартам ГОСТ 19 и ГОСТ 34.
*   **Технический вызов и решение:** Устройства от разных вендоров передавали телеметрию и статусы в разнородных форматах. Для устранения конфликтов я спроектировала промежуточный адаптер и описала единую модель маппинга входящих статусов. Построила ER-диаграмму реляционной БД на 11 таблиц в 3НФ и составила подробный словарь данных. Это исключило хаос в архитектуре и минимизировало количество доработок на этапе интеграции оборудования.

#### 2. Микросервисный финтех-модуль страхового сервиса «Lucky Insurance»
*   **Что сделано:** Провела системный анализ и декомпозицию процесса автоматического расчета скоринга клиентов на основе исторических финтех-данных. Спроектировала структуры данных для безопасного хранения финансовых профилей юридических и физических лиц. 
*   **Технический вызов и решение:** Требовалось организовать быстрый обмен данными без пиковых нагрузок на бэкенд. Настроила асинхронный маппинг транзакционных данных между внутренними сервисами компании через брокер сообщений Apache Kafka, что повысило отказоустойчивость системы при обработке финансовых расчетов.

#### 3. Интеграционный модуль онлайн-кинотеатра «Otium»
*   **Что сделано:** Спроектировала REST API контракты (JSON/XML) для сквозной логики гибкой сортировки, пагинации и динамической фильтрации каталога контента. 
*   **Технический вызов и решение:** Для точечной оптимизации запросов к бэкенду и разгрузки систем описала межсервисные потоки данных между Web Server и микросервисами Films/Series с помощью UML Sequence-диаграмм. Заложила в сценарии Sequence обработку сетевых ошибок, таймаутов и логирование, что позволило разработчикам сократить время отладки кода.

#### 4. Мобильное приложение медицинской сети «Вита»
*   **Что сделано:** Провела предпроектный анализ предметной области и выстроила карту пользовательских историй (User Story Mapping) для приоритизации бэклога в рамках методологии Agile/Scrum. 
*   **Технический вызов и решение:** Процесс записи на диагностику содержал много ручных шагов. Я оптимизировала сквозной бизнес-процесс по модели TO-BE в нотации BPMN 2.0, полностью исключив ручное участие администраторов. Разработала диаграммы состояний талонов (UML State Machine) и интерактивные low-fidelity прототипы экранов, что сократило время оформления заявки клиентом и свело к нулю ошибки ручного ввода данных.
