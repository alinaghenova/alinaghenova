### 1. [ИТ-платформа автоматизации «Умный дом» (Stets Home)](https://github.com)

### 2. [Интеграционный модуль и REST API онлайн-кинотеатра «Otium»](https://github.com)
*REST API, Swagger (OpenAPI), JSON, UML Sequence* — постановка задач на разработку и проектирование логики рейтинга кинокритиков и сортировки каталога.
- Проанализировала 3 микросервиса в Swagger и спроектировала изменения для 7 методов REST API (query-параметры `sortBy`, `direction` и расширение JSON-ответов).
- Отрисовала UML Sequence-диаграмму на 6 участников с опциональными блоками (`opt`) и зафиксировала правило вывода `null`-рейтингов в конец выдачи.
- Сократила время на согласования (Back-and-Forth) с разработчиками на 50% и обеспечила прозрачную оценку спринта.

### 3. [Мобильное приложение и реинжиниринг процессов сети клиник «Вита»](https://github.com)
*BPMN 2.0 (AS-IS / TO-BE), UML State Machine, DFD, User Stories, Figma* — цифровизация записи на приём, лабораторных анализов и электронных назначений.
- Провела реинжиниринг процесса записи (TO-BE в BPMN 2.0), исключив роль администратора (сокращение с 3 до 2 ролей) и внедрив автоуведомления по таймеру за 24 часа.
- Описала жизненный цикл заявки в UML State Machine (6 статусов), потоки данных DFD (хранилища `D1`–`D6`) и собрала 21 экран в Figma/Draw.io.
- Сократила время записи пациента на приём на 25% и автоматизировала выдачу PDF-результатов анализов.

### 4. [Микросервисная архитектура (C4) и REST API сервиса страхования LUCKY](https://github.com)
*C4 Container Diagram, REST API, OpenAPI 3.0 (YAML), Swagger, Kafka, RabbitMQ, MongoDB* — проектирование архитектуры нового страхового продукта для домашних животных.
- Интегрировала новый микросервис `Insurance` с базой MongoDB (паттерн Database per service) в контур из 7 микросервисов и 4 внешних систем (`PAY-PAY`, `SHIP-SHIP`, `CRM`, `Amazon S3`).
- Настроила переиспользование корзины (`Shopping cart` через Kafka) и оплаты (`Payment` через RabbitMQ) для запуска MVP с SLA ответа ≤ 10 секунд.
- Разработала спецификацию контракта `GET /insurance` в формате OpenAPI 3.0 (YAML) с UUID-идентификацией, тарифами и кодами ошибок (`400`, `401`, `500`).
