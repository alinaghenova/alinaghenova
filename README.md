### 📁 Избранные проекты (как работа аналитика)

* **Платформа автоматизации «Умный дом» (дипломный проект)**
  Спроектировала MVP на 27 фич: подготовила SRS‑спецификацию, декомпозировала бэклог на 8 эпиков, построила ER‑диаграмму на 11 таблиц в 3 НФ.  
  Ключевая сложность: устройства разных вендоров возвращают статусы в разных форматах. Решение: ввела промежуточный адаптер и маппинг статусов в единую модель — это снизило количество доработок на этапе интеграции.

* **Интеграционный модуль онлайн‑кинотеатра «Otium»**
  Спроектировала REST API контракты и сквозную логику фильтрации каталога. Построила UML Sequence‑диаграммы для межсервисных потоков — это помогло команде заранее увидеть узкие места и заложить обработку ошибок и таймаутов.

* **Мобильное приложение медицинской сети «Вита»**
  Провела предпроектный анализ и построила карту пользовательских историй (USM). Оптимизировала процесс записи на диагностику по модели TO‑BE: исключила ручное участие администраторов, что сократило время оформления заявки и уменьшило количество ошибок при вводе данных.
